## how posts work

Each post is a plain markdown file. Fenced code blocks get highlighted automatically:

```bash
git clone https://github.com/bluenets1/bf1pr
cd bf1pr && make
```

> [!TIP]
> Add `title=file.ext` and `{1,3-4}` after the language to name a block and highlight lines.

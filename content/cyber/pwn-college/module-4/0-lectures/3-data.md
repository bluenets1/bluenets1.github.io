## AND Gate (&)
- This gate outputs "on" (1) only when **both** inputs A and B are "on" (1).
- If either input is "off" (0), the output Q is "off" (0).
## “Greater Than or Equal to 1” Gate (≥1)
- This gate outputs "on" (1) if **at least one** input (A or B) is "on" (1).
- If both are "off" (0), the output Q remains "off" (0).
## “Equals 1” Gate (=1)
- This gate checks if **exactly one** of the inputs is "on" (1).
- If both A and B are "off" (0) or both are "on" (1), output Q is "off" (0).
- If only one is "on" (1), output Q is "on" (1).
## “Is 1” Gate (1)
- This single-input gate outputs "on" (1) only if A is "on" (1).
- If A is "off" (0), output Q is also "off" (0).
These gates convert simple binary signals ("on"/"off" or "1"/"0") to logical operations that form the foundation of digital circuits and computer decision-making.
